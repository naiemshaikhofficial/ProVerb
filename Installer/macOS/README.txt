======================================================================
               Producer Toy ProVerb - macOS Release
======================================================================

Welcome to ProVerb by Producer Toy!

INSTALLATION:
1. Double-click "Install ProVerb.pkg".
2. Follow the on-screen installer prompts.
3. Administrator password will be requested to install the audio plugins
   into your system /Library/Audio/Plug-Ins folders.
4. Restart your DAW (Logic Pro, FL Studio, Ableton Live, Cubase, etc.).

SUPPORTED FORMATS:
• Audio Unit (AU): Logic Pro, GarageBand, Ableton Live
• VST3: FL Studio, Ableton Live, Cubase, Studio One, Reaper, Bitwig
• AAX: Avid Pro Tools 11+

NATIVE ARCHITECTURES:
• Apple Silicon (M1, M2, M3, M4)
• Intel 64-bit Core

UNINSTALLATION:
To cleanly uninstall all ProVerb plugin components, double-click
"Uninstall ProVerb.command" in this disk image and follow the prompt.

SUPPORT & ACTIVATION:
• Website: https://producertoy.com
• License: Enter your activation key inside the plugin UI.
