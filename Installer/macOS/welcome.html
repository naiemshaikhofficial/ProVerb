Welcome to ProVerb

Universal Audio Plugin for macOS

This installer will set up ProVerb 1.0.0 with native support for both Apple Silicon (M1/M2/M3/M4) and Intel Macs.

Available Formats:

  • Audio Unit (AU / .component): Optimized for Apple Logic Pro, GarageBand, and Ableton Live.
  • VST3 (.vst3): Universal 64-bit for FL Studio (Mac), Ableton Live, Cubase, Studio One, Reaper, and Bitwig.
  • AAX (.aaxplugin): Native 64-bit for Avid Pro Tools 11+.
Click Continue to configure your desired plugin formats and proceed with the installation.
